# Créditos e origem

O Projeto Farol parte do material da **Imersão Databricks + Claude Code**, da **Jornada de Dados**, criada por
**Luciano Vasconcelos**:

- Repositório de origem: [lvgalvao/ImersaoControlTower](https://github.com/lvgalvao/ImersaoControlTower)
- Jornada de Dados: [suajornadadedados.com.br](https://suajornadadedados.com.br)

Este repositório é uma adaptação mantida por **Ramon Ribeiro Feliciano**, com estrutura de pastas, nomes de arquivos e
documentação reorganizados como um projeto de engenharia de dados.

O cenário, a Vértice Tecnologia e todos os dados são **fictícios**. Os dados são gerados por
[`data/gerar_dataset.py`](data/gerar_dataset.py) com seed fixa.
